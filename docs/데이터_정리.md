## 산정보 서비스 필드 (4,705건, 고유 코드 4,650)

mntiname(산명), mntilistno(코드 — 명산 mntncd와 같은 체계), mntiadd(소재지), mntihigh(높이), mntiadmin/mntiadminnum(관리기관·전화),
mntidetails(설명: 1,718개 산만 실제 내용), mntitop(100대명산 선정이유, 99건), mntisname·mntisummary(거의 비어 있음).

- **소요시간·좌표 없음** → 추천 대상(시간 질문)으로 확장 불가. 높이로 시간을 추정하면 데이터에 없는 값이므로 하지 않음.
- 쓸 수 있는 곳: 결과 화면에 관리기관 전화번호 표시 정도 (선택).

## 산 정보 조회_GW 필드 (1,338건)

mntnnm, mntnid, mntninfohght(높이), mntninfopoflc(소재지), mntnsbttlinfo(부제, 965), mntninfodtlinfocont(설명, 1,066),
pbtrninfodscrt(교통, 399), mntnattchimageseq(**산 사진 URL**), mntninfomngmemnbdnm/mntninfomangrtlno(관리기관, 거의 없음).
값 상당수가 `&nbsp;` 자리표시(이중 이스케이프) → 채움률은 정제 후 기준.

- **좌표 없음, 추천코스(ptmntrcmmncoursdscrt) 0건**
- 설명문 속 시간 표현: 명산 외 60개 산, 그중 '총 산행시간'으로 볼 만한 것 21개. 편도/이동시간과 섞여 있어 **추천 대상 확장에는 안 씀**
- **쓰는 곳: 결과 화면 산 사진** — 명산 95곳 중 94곳 매칭(산명+높이 ±30m, 동명이산 24곳은 높이로 구분), https로 로드 확인. 카드에는 넣지 않음(CORS)
